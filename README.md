# Banking Management System in C++

## About the Project
This is a console-based Banking Management System developed using C++. It allows users to create customers and bank accounts, deposit and withdraw money, transfer funds between accounts, and view account details and transaction history.

The project demonstrates Object-Oriented Programming (OOP) concepts and basic banking operations.

## Features
- Create Customer
- Create Bank Account
- Deposit Money
- Withdraw Money
- Transfer Money Between Accounts
- Display Customer Information
- Display Account Details and Balance
- View Transaction History
- Validate customer IDs and account numbers
- Prevent withdrawals and transfers when the balance is insufficient
- Menu-driven interface

## Technologies Used
- C++
- iostream
- string
- iomanip

## OOP Concepts Used
- Classes and Objects
- Constructors
- Member Functions
- Arrays of Objects
- Encapsulation basics
- Pass by Reference
- Conditional Statements and Loops

## How It Works
1. Create a customer by entering their ID, name, and phone number.
2. Create a bank account linked to an existing customer.
3. Deposit money into an account.
4. Withdraw money if sufficient balance is available.
5. Transfer money from one account to another.
6. View customer and account information.
7. Check the transaction history of an account.
8. Exit the program using the menu.

## How to Run
1. Clone or download this repository.
2. Open `task3.cpp` in a C++ IDE or compiler.
3. Compile the source code.
4. Run the program and select an option from the menu.

## Learning Objectives
This project helps beginners understand:
- Object-Oriented Programming in C++
- Working with multiple classes
- Constructors and objects
- Arrays and functions
- Account balance management
- Transaction recording
- Basic input validation

## Limitations
- Customer and account information is stored in arrays in memory.
- Data is not saved permanently after the program ends.
- The program is intended for educational purposes, not real banking use.
